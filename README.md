### Security tools

- 📡 **[beacon-spectrum](https://github.com/blurxy/beacon-spectrum)**: finds periodic C2 beaconing in connection timing alone with a Rayleigh / Z² periodogram. No payload or TLS inspection; dependency-free pcap and Zeek ingest.
- 🔍 **[aur-build-diff](https://github.com/blurxy/aur-build-diff)**: builds two revisions of an AUR package under bubblewrap and strace and diffs what each one actually does: new outbound endpoints, new binaries, writes outside the build tree. DNS is blocked at the systemd-resolved socket, not just the network namespace.
- 🐍 **[py-exec-mcp](https://github.com/blurxy/py-exec-mcp)**: runs Python from an MCP client over stdin, so no shell re-parses your code. On PyPI: `uvx py-exec-mcp`.
